# Дневник академии

Веб-приложение барбер-академии: путь ученика от заявки до выпуска — модерация, домашние задания с фото, проверка преподавателем, чат, уведомления и публичное портфолио. Работает как сайт и мини-приложение MAX; бот MAX дублирует ключевые действия. Файлы хранятся в S3-совместимом хранилище.

## Быстрый старт

```bash
cp .env.example .env    # необязательно: без .env поднимаются сайт и API, бот не запускается
docker compose up --build
```

Сайт — http://localhost:8080.

## Демо для жюри

С `DEMO_MODE=true` на экране входа появляются кнопки «Войти как администратор / преподаватель / ученик», а в приложении — панель «Демо», которая создаёт новые работы, заявки и сообщения в реальном времени.
